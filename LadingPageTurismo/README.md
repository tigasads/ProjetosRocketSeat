Landing Page Turismo — Conheça Busan

Sobre o projeto

Este projeto consiste no desenvolvimento de uma landing page sobre a cidade de Busan, localizada na Coreia do Sul.
A página apresenta alguns dos principais pontos turísticos da cidade, destacando suas características históricas, culturais e turísticas por meio de imagens e descrições.
O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento web, utilizando HTML5 e CSS3.

Demonstração
Tecnologias utilizadas
HTML5
CSS3
Google Fonts (Open Sans)

Como executar o projeto
Clone o repositório:
git clone https://github.com/tigasads/ProjetosRocketSeat.git

Acesse a pasta do projeto:
cd ProjetosRocketSeat/LadingPageTurismo

Abra o arquivo index.html em seu navegador.

Conceitos praticados
Estruturação de páginas utilizando HTML5.
Utilização de elementos semânticos.
Estilização de elementos com CSS3.
Organização de conteúdo por meio de classes e identificadores.
Trabalhando com imagens e tipografia.
Utilização de fontes externas com Google Fonts.
Personalização de listas utilizando pseudo-elementos CSS.
